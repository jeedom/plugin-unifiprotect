# UniFi Protect for Jeedom

Jeedom plugin using the official local UniFi Protect Integration API with `X-API-Key` authentication.

Supported features are controller, camera and chime discovery, connection-state polling, and camera snapshots. Features not exposed by the official API are documented in `docs/en_US/index.md`.

Run the standalone client tests with:

```shell
sh tests/run_tests.sh
```
